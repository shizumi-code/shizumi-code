## Tools

### IllustriousTagTool

IllustriousTagTool is an offline Windows desktop tool that generates
tag classification candidates from natural language input using a local LLM.

- Current Version: **Free MVP v0.1.1**
- Platform: Windows
- Execution: Fully offline
- Purpose: Generate classification candidates only  
  (final decisions must be made by a human)
